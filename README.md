# 📧 EdTech Email Management System

## 📖 About the Project
A comprehensive, multi-module web application developed for the Educational Technology Center of Liceo de Cagayan University. This system streamlines the management of email records, Google Workspace licenses, training/seminar tracking, and account retrieval processes.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL (Hosted on Clever Cloud)
* **Libraries/Tools:** PhpWord (for exporting reports)

## ✨ Key Features
* **Secure Authentication:** Password hashing and session-based login.
* **Full CRUD Operations:** Manage department email records and user accounts easily.
* **Advanced Filtering:** Sort and paginate records by department and request type.
* **Data Management:** Bulk import/export capabilities via CSV and Word formats.
* **Safety First:** Undo-delete feature with session-based recovery.
